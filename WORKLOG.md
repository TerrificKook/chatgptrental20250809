## Решения
React + TypeScript + Vite, собственный CSS, hash-маршруты, IndexedDB. Тёплая основа, глубокий бирюзовый акцент, каталог сразу после поиска. Нет внешних шрифтов и отправки данных. Avito не открылся веб-инструментом, ограничения не обходим; используем логику из ТЗ.

## Маршруты
